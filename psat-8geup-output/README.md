# 국회직 8급 PSAT 합격 패키지 (생성 산출물)

PSAT 유형 **15개를 1:1 전문 에이전트로 병렬 조사**하고 **검수관 1개**가 합격 루브릭으로
채점·통합한 멀티 에이전트 오케스트레이션의 산출물이다. 대상 시험은 **국회직 8급 1차 PSAT**
(언어논리 20 + 상황판단 20 + 자료해석 20 = 60문항, 경쟁 합격선 2025년 약 80점/48·60).

## 구성

| 파일 | 내용 |
|---|---|
| `PSAT합격-패키지.md` | 머리말 + 1부 시간배분표 + 2부 영역별·유형별 공략 15개(전략 + 대표 예제 카드). 학습용 본책. |
| `판정표.md` | 기존 **4축** 루브릭 채점 결과 → **15/15 합격**. |
| `판정표-엄격.md` | **5축 강화** 기준 재채점 → **15/15 보완**(아래 참조). 약점 감사 문서. |
| `시간배분표.md` | 교시별 유형 우선순위·버릴 순위·문항당 목표 시간 + 정합성 점검. |
| `sections/` | 유형별 원자료 15개(출제비중·풀이전략·예제카드·출처). 패키지 2부의 원본. |

## 두 가지 검수 결과 (중요)

- **4축 기준(`판정표.md`)**: 출제비중 근거 / 전략 완성도 / 예제카드 ≥8개 / 함정 포인트 → **전 15유형 합격**.
- **5축 강화 기준(`판정표-엄격.md`)**: 위 4축에 **① 회차별 실측 비중**, **③ 실수치 worked example**,
  **⑤ 1차 출처(기출 원본·시행처)** 를 더 엄격히 요구 → **전 15유형 보완**.
  - 강등 결정타: **③ 예제 카드에 실제 수치 계산이 든 worked example 부재**(04·13 제외)와
    **⑤ 출처가 위키·블로그·강사 자료 위주**(기출 원본 직접 인용은 09뿐).
  - **전략(②)·함정(④)은 거의 전 섹션 O** — 운영 골격은 단단하므로 **재작성이 아니라 보강으로 합격 전환 가능**.
  - 합격 전환 1순위: **13**(카드 O), **04**(카드 O), **09**(출처 O) — 1차 출처 + worked example 2~3개만 채우면 O.

## 생성 방식 · 한계 (투명성)

- Claude 멀티 에이전트(유형별 전문가 15 + 검수관)로 생성. 각 에이전트는 **WebSearch**로 한국어
  기출 해설·분석 자료를 복수 출처 교차검증해 작성했다.
- **WebFetch가 다수 한국 사이트에서 403 차단**되어, 본문 정독이 아니라 **검색 스니펫 기반 합성**이다.
- **출제 비중은 추정치**다. 국회직 8급 자체 기출은 2025년 1회뿐이라, 모(母)시험인
  **국가직 7급·민간경력자(민경채)·5급/입법고시** 분포에서 환산했다(난도: 민경채~7급 사이).
- **예제 카드는 기출 문항 전문을 복제하지 않고** 구조·풀이 단계로 재서술한 것이다.
- 위 한계로 인해 `판정표-엄격.md`가 지적하듯 현 상태는 "진짜 합격 수준"으로 단정하기 어렵다.
  실제 활용 전 **기출 원본 대조 + worked example 보강**을 권장한다.

## 사용법

1. `시간배분표.md`로 교시별 시간 설계(풀이 우선순위·버릴 순위)를 익힌다.
2. `PSAT합격-패키지.md` 2부에서 유형을 하나씩 골라 전략 → 예제 카드 순으로 훈련한다.
3. `판정표-엄격.md`의 유형별 "강화 보완 지시"를 보강 학습 체크리스트로 활용한다.
