# 한능검 2급 대비 — 멀티 에이전트 조사 시스템

Claude Code (Opus 4.8 / 1M context / Max / 빠름)에서 **항목 13개를 1:1 전문 에이전트**로
병렬 조사하고, **검수관 1개**가 결과를 한국사능력검정시험 2급 합격 수준으로 판정·통합하는 구조.

## 구성

| 역할 | 파일 | 담당 |
|---|---|---|
| 검수관(로컬+판정) | `00-judge-coordinator.md` | 로컬 출력 파일 소유, 2급 루브릭 적용, 보완 지시, 최종 패키지 조립 |
| 시대 ①~⑧ | `01`~`08` | 각 시대 1개씩 전문 조사 |
| 주제 ⑨~⑬ | `09`~`13` | 단골 출제 유형 1개씩 전문 조사 |

## 실행 흐름 (메인 세션이 지휘)

서브에이전트는 다른 서브에이전트를 못 부르므로, **dispatch는 메인 세션**이 한다.

1. 메인 세션이 13개 전문 에이전트를 **한 번에 병렬 호출**한다(빠름).
   각 에이전트는 `output/sections/{번호}-{영역}.md`에 자기 섹션을 쓴다.
2. 13개가 끝나면 메인 세션이 `judge-coordinator`를 호출한다.
3. 검수관이 13개 섹션을 읽고 **2급 루브릭**으로 채점 → `output/판정표.md`에 합격/보완 기록.
4. '보완 필요' 항목이 있으면 메인 세션이 해당 번호 에이전트만 다시 호출(검수관의 gap 메모를 프롬프트에 첨부).
5. 전 항목 합격이면 검수관이 `output/한능검2급-패키지.md` (①기출비중표 + ②핵심요약 + ③암기카드 통합)를 조립한다.

## 폴더 레이아웃 (작업 디렉터리 기준)

```
output/
  sections/        # 각 전문 에이전트가 쓰는 원자료 13개
  판정표.md         # 검수관의 항목별 합격/보완 판정
  한능검2급-패키지.md # 최종 통합 산출물
```

## 2급 기준 (검수관·전 에이전트 공통 인지)

- 심화 50문항, 70점 이상 = 2급. 문항당 1~3점 차등.
- 정답 개수 기준 **안정권 = 40개 이상(80%)** 을 목표로 잡는다.
- 1급용 지엽 암기는 제외. 비중 큰 **고대·고려·조선**을 최우선으로 두껍게.

## 메인 세션에 붙여 쓸 첫 지시문(예시)

> 작업 디렉터리에 `output/sections/` 폴더를 만들어라. `.claude/agents/`의 전문
> 에이전트 13개(01~13)를 병렬로 호출해 각자 섹션 파일을 쓰게 하라. 모두 끝나면
> `judge-coordinator`를 호출해 2급 루브릭으로 판정하고, 보완 항목은 재호출하라.
> 전 항목 합격 시 통합 패키지를 조립하라.
