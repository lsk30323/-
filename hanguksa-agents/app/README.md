# 한능검 2급 합격 마스터 — 학습 PWA

한국사능력검정시험 **2급 대비 설치형 웹앱(PWA)**. 빌드 도구 없는 순수 HTML/JS, 오프라인 동작.

## 기능
- **모의고사 5회분(250문항)** 응시 — 80분 타이머 → 자동 채점 → 점수·예상 급수 + 영역별 정답률
- **문항별 해설** — 정답 근거 + 오답 4개 반박 + 한 줄 정리
- **오답노트(자동 저장)** — 틀린 문제 누적·영역별 그룹·복습 풀이
- **영역 연습** — 13개 영역 랜덤 풀이(즉시 정답·해설)
- **개념·D-7 요약** — 시대 뼈대·必出 순서·함정 짝·주제 매칭·점수 환산표

## 구성 파일
```
app/
├── index.html              앱 본체(UI + 로직)
├── manifest.webmanifest     PWA 매니페스트
├── sw.js                    서비스워커(오프라인 캐시)
├── icon-192.png / icon-512.png
└── data/
    ├── exam-1.js ~ exam-5.js  모의고사 250문항(문제+정답+해설)
    └── concepts.js            개념·D-7 요약 데이터
```

## 실행 방법

### A. PC에서 바로 보기
PWA 기능(설치·오프라인)은 http(s)에서만 동작합니다. 앱 폴더에서 간단한 서버를 띄우세요:
```
cd app
python3 -m http.server 8000
```
브라우저에서 **http://localhost:8000** 접속 → 데스크톱 Chrome이면 주소창의 "설치"로 앱 설치 가능.

> 서버 없이 `index.html`을 더블클릭해도 **문제 풀이·채점·해설은 정상 동작**합니다. 다만 설치/오프라인 캐시는 안 됩니다.

### B. 폰에 설치 (권장)
1. `app` 폴더를 정적 호스팅에 올립니다 — 가장 쉬운 방법:
   - **Netlify Drop**: <https://app.netlify.com/drop> 에 `app` 폴더를 드래그(가입 없이 즉시 URL 발급).
   - **GitHub Pages**: 이 저장소에서 Pages를 켜면 `https://<아이디>.github.io/-/hanguksa-agents/app/` 로 접속(앱이 상대경로라 하위 경로에서도 동작).
   - 그 외 Vercel·Cloudflare Pages 등 어떤 정적 호스트든 가능.
2. 폰 브라우저로 발급된 **https 주소** 접속.
3. **홈 화면에 추가** — Android Chrome: 메뉴 → "앱 설치" / iOS Safari: 공유 → "홈 화면에 추가".
4. 설치 후 **오프라인**으로도 실행됩니다.

## 메모
- 점수·오답노트는 브라우저 **localStorage**에 저장됩니다(기기·브라우저별, 서버 전송 없음).
- 모든 문항은 검증된 학습 자료(`output/`)에서 추출했으며, 정답은 모의고사 정답표와 100% 일치합니다.
- 문항 추가/수정은 `data/exam-*.js`를 편집하면 즉시 반영됩니다.
